A 4 KB chess engine in Python: 0x88 board, alpha-beta search with quiescence, a transposition table and MVV-LVA move ordering, at a fixed 150k-node budget per move. Deterministic, standard library only. It plays through the make.fun trial environment (`MAKEFUN_ENV_URL`, `MAKEFUN_PROMPT_FILE`).

## Run it

```sh
python3 main.py
```
